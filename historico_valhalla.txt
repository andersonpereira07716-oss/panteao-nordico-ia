### ⚡ THOR — A Arquitetura da Forja (Execução no Termux)
> *"Menos conversa, mais impacto. Eis como erguer essa muralha usando apenas o seu terminal, tão pesado quanto o Mjölnir!"*

Para rodar rápido no **Termux**, vamos usar **Node.js** com um frontend ultra-leve (Vite + Vanilla JS ou React) consumindo o client oficial do Supabase:

#### 1. No Termux (Preparando o Terreno):
```bash
# Atualize as runas e instale o Node
pkg update && pkg install nodejs-lts -y

# Crie a estrutura relâmpago
npm create vite@latest supabase-login -- --template vanilla
cd supabase-login
npm install @supabase/supabase-js
npm run dev -- --host
```
*(Abra o navegador no celular em `http://localhost:5173`)*

#### 2. O Código do Relâmpago (`main.js`):
```javascript
import { createClient } from '@supabase/supabase-js'

const supabase = createClient('SUA_URL_SUPABASE', 'SUA_ANON_KEY')

// Função de Login Rápido via Magic Link (Sem Senha)
async function loginRapido(email) {
  const { data, error } = await supabase.auth.signInWithOtp({
    email: email,
    options: {
      emailRedirectTo: window.location.origin, // Redireciona de volta pro app
    },
  })
  if (error) alert("Falha: " + error.message)
  else alert("Runas enviadas! Olhe seu e-mail e entre direto.")
}

// Escuta a sessão ativa em tempo real
supabase.auth.onAuthStateChange((event, session) => {
  if (session) {
    document.body.innerHTML = `<h1>Bem-vindo ao Valhalla, ${session.user.email}!</h1>`
  }
})
```

### `components/MjolnirButton.tsx`

```tsx
import React from 'react';
import { 
  TouchableOpacity, 
  Text, 
  ActivityIndicator, 
  TouchableOpacityProps 
} from 'react-native';

// Variantes forjadas para diferentes propósitos em batalha
type ButtonVariant = 'primary' | 'secondary' | 'danger' | 'outline';
type ButtonSize = 'sm' | 'md' | 'lg';

interface ButtonProps extends TouchableOpacityProps {
  title: string;
  variant?: ButtonVariant;
  size?: ButtonSize;
  isLoading?: boolean;
}

export const MjolnirButton: React.FC<ButtonProps> = ({
  title,
  variant = 'primary',
  size = 'md',
  isLoading = false,
  disabled,
  className = '',
  ...rest
}) => {
  // 1. Definição do peso e espaço do botão (Dimensões)
  const sizeStyles: Record<ButtonSize, { container: string; text: string }> = {
    sm: { container: 'py-2 px-3 rounded-md', text: 'text-sm' },
    md: { container: 'py-3 px-5 rounded-lg', text: 'text-base font-semibold' },
    lg: { container: 'py-4 px-6 rounded-xl', text: 'text-lg font-bold' },
  };

  // 2. Cores extraídas do coração das estrelas (Variantes)
  const variantStyles: Record<ButtonVariant, { container: string; text: string }> = {
    primary: {
      container: 'bg-amber-500 active:bg-amber-600 border border-amber-400',
      text: 'text-slate-950',
    },
    secondary: {
      container: 'bg-slate-800 active:bg-slate-700 border border-slate-700',
      text: 'text-slate-100',
    },
    danger: {
      container: 'bg-red-600 active:bg-red-700 border border-red-500',
      text: 'text-white',
    },
    outline: {
      container: 'bg-transparent border-2 border-amber-500 active:bg-amber-500/10',
      text: 'text-amber-500',
    },
  };

  // 3. Modificadores de estado (Desabilitado ou Carregando)
  const isDisabled = disabled || isLoading;
  const opacityStyle = isDisabled ? 'opacity-50' : 'opacity-100';

  return (
    <TouchableOpacity
      activeOpacity={0.8}
      disabled={isDisabled}
      className={`flex-row items-center justify-center shadow-md ${sizeStyles[size].container} ${variantStyles[variant].container} ${opacityStyle} ${className}`}
      {...rest}
    >
      {isLoading ? (
        <ActivityIndicator 
          size="small" 
          color={variant === 'primary' ? '#020617' : '#f8fafc'} 
        />
      ) : (
        <Text 
          className={`text-center tracking-wider ${sizeStyles[size].text} ${variantStyles[variant].text}`}
        >
          {title}
        </Text>
      )}
    </TouchableOpacity>
  );
};
```

### Instruções de Forja no Termux

Execute os encantamentos no seu terminal Android para preparar o terreno:

1. **Instale os utilitários de Tailwind (NativeWind):**
   ```bash
   pkg install nodejs-lts
   npm install nativewind tailwindcss react-native-reanimated
   npx tailwindcss init
   ```

2. **Configure o `tailwind.config.js`:**
   ```javascript
   /** @type {import('tailwindcss').Config} */
   module.exports = {
     content: ["./App.{js,jsx,ts,tsx}", "./components/**/*.{js,jsx,ts,tsx}"],
     theme: {
       extend: {},
     },
     plugins: [],
   };
   ```

3. **Invoque no seu `App.tsx`:**
   ```tsx
   import { View } from 'react-native';
   import { MjolnirButton } from './components/MjolnirButton';

   export default function App() {
     return (
       <View className="flex-1 justify-center items-center bg-slate-900 px-4 gap-4">
         <MjolnirButton title="GOLPE DO TROVÃO" variant="primary" size="lg" />
         <MjolnirButton title="ESCUDO DE ASGARD" variant="secondary" />
         <MjolnirButton title="CARREGANDO FORÇA..." isLoading variant="outline" />
       </View>
     );
   }
   ```
